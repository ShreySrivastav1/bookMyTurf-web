# ⚽ BookMyTurf

BookMyTurf is a full-stack sports turf booking platform that allows users to discover, view, and book sports turfs online. Turf owners can manage their venues, availability, and bookings through a dedicated dashboard.

## 🚀 Live Demo

🔗 http://13.127.251.76/

## 📌 Backend Repository

🔗 https://github.com/ShreySrivastav1/BookMyTurf

---

## ✨ Features

### Users

- Browse available sports turfs
- View turf details
- Check available slots
- Book turfs online
- Secure authentication
- Razorpay payment integration
- View booking history
- Cancel bookings

### Turf Owners

- Become a turf owner
- Create turfs
- Edit turf details
- Delete turfs
- View owned turfs
- Manage bookings

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/ShreySrivastav1/BookMyTurf-web.git
```

### Install Dependencies

```bash
npm install
```

### Create Environment Variables

```env
VITE_BASE_URL=http://localhost:7777
VITE_RAZORPAY_KEY=your_razorpay_key
```

### Run Application

```bash
npm run dev
```

---

## 🌐 Deployment

The frontend is deployed on AWS EC2 and served through Nginx.

### Deployment Architecture

```text
User Browser
      │
      ▼
React + Vite Frontend
      │
      ▼
Nginx Reverse Proxy
      │
      ▼
Node.js Backend
      │
      ▼
MongoDB Atlas
```
